# TOPMANIDMB Orbit Emblem

Selected concept: 04 — Orbit Emblem

The mark combines:

- a gold command shield;
- a circuit-inspired `T` monogram;
- four orbital nodes for global monitoring;
- a cyan intelligence signal;
- the TOPMANIDMB navy, gold, and cyan palette.

## Source and export mode

- Source mode: generated raster concept selected by the user.
- Source file: `orbit-emblem-master-1254.png`.
- Export mode: deterministic ImageMagick resize from the selected source.
- Master app export: `orbit-emblem-1024.png`, RGB, no alpha.
- Preview: `orbit-emblem-export-preview.png`.

The active copies are exported into `public/favico`, `public/brand`, and the
iOS asset catalog. The former SVG mark remains in the repository as a legacy
rollback asset but is no longer used by the main header.
