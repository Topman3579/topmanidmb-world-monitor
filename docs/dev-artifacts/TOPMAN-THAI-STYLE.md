# TOPMAN News Room · หลักภาษาไทย

อัปเดต: 2026-08-05 · ใช้กับหน้าหลัก / โหมดใช้ง่าย / บทสรุปบริหาร

## เป้าหมาย

**รวบรวม · เรียบเรียง · วิเคราะห์ · นำเสนอข้อมูล** ให้ **ผบ.ตร.** และ **นายกรัฐมนตรี**
เพื่อ **เข้าใจข่าวสารและตัดสินใจ** — ไม่ใช่โทนฟีดข่าวหรือโซเชียล

ภาษาไทยราชการกระชับ อ่านเข้าใจใน 30 วินาที

## กติกา

1. **ค่าเริ่มต้นเป็นไทยล้วน** (`topmanMode=th`) — ไม่แสดง `ไทย / English` คู่กันโดยอัตโนมัติ
2. **เก็บคำเฉพาะอังกฤษ** เมื่อเป็นชื่อผลิตภัณฑ์ ตัวย่อมาตรฐาน หรือชื่อช่อง:
   - TOPMAN News Room, World Monitor, Pro, Business, MCP, SET, HLS, Dashboard (เมื่อจำเป็น)
3. **ห้ามทับศัพท์เพี้ยน** เช่น ไม่เขียน “นิวส์รูม” แทน News Room เมื่อใช้เป็นชื่อแบรนด์
4. **แยกชั้นข้อมูลเสมอ**
   - ข้อเท็จจริงจากแหล่งที่ตรวจสอบได้
   - ข้อจำกัด / ช่องว่างข้อมูล
   - รายการที่ต้องยืนยันจากช่องทางทางการ (เช่น ศบ.ทก. / กต. / ปภ.)
5. **ห้ามแต่งข้อเท็จจริง** — ไม่มีข้อมูล = บอกตรง ๆ ว่ายังสรุปไม่ได้
6. **ข้อความ LINE** สั้น 4–6 ประเด็น · รายละเอียดยาวอยู่ในบันทึกสรุปผู้บริหาร

## โครงบรีฟรายวัน (08:00)

1. ข้อความ LINE ถึง ผบ.ตร. / นายกรัฐมนตรี (สั้น)
2. บันทึกสรุปผู้บริหาร (ความมั่นคง / ภัยพิบัติ / พลังงาน / ตลาด + ข้อเสนอติดตาม)
3. สถานะ: ร่าง → อนุมัติแล้ว → ส่งแล้ว (ต้องมีคนตรวจก่อนส่ง LINE OA)
